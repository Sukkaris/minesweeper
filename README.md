# Minesweeper（iPhone 用 PWA）

iPhone の Safari から「ホーム画面に追加」して遊ぶ、個人用のマインスイーパーです。
素の HTML / CSS / JavaScript だけで作られており、インストール後は完全にオフラインで動作します。

- 公開 URL: https://sukkaris.github.io/minesweeper/
- 難易度の切り替え（暫定）: URL の末尾に `?level=beginner` / `?level=intermediate` / `?level=advanced` を付けて開く。
  一度開くとその難易度が保存され、ホーム画面から起動したときも同じ難易度になります。

---

## 1. アイコンの生成手順

アイコンの元データは `icons/icon.svg`（地雷のシルエット）です。
これを PNG に変換したものが `icons/` に置いてあります。意匠を変えたときは次の手順で作り直します。

1. `tools/generate-icons.html` をブラウザで開く
   - ローカルサーバー経由で開くと `icon.svg` が自動で読み込まれます
   - ファイルを直接（`file://` で）開いた場合は自動読み込みに失敗するので、
     画面のテキストエリアに `icon.svg` の中身を貼り付けて「貼り付けた SVG を使う」を押す
2. 「3 サイズをまとめてダウンロード」を押す（または各サイズの「ダウンロード」を押す）
3. ダウンロードされた 3 つのファイルを `icons/` フォルダに上書きで置く
   - `apple-touch-icon.png`（180×180）
   - `icon-192.png`（192×192）
   - `icon-512.png`（512×512）

`tools/` フォルダは開発用なので、Service Worker のキャッシュ対象には含まれていません。

## 2. コードを更新したら必ずやること（重要）

**`sw.js` の先頭にあるバージョン番号を 1 つ増やしてください。**

```js
const CACHE_VERSION = 1;   // ← ここを 2, 3, 4 … と増やす
```

このアプリは、一度ホーム画面に入れると、ファイルを端末内に丸ごと保存して
そこから起動します（だからオフラインで動きます）。
バージョン番号が同じままだと「新しいファイルがある」と気付けず、
GitHub に push しても **ホーム画面のアプリは古いまま** です。

番号を増やして push すると、次にアプリを起動したときに画面上部に
「新しいバージョンがあります ／ 再読み込み」のバナーが出ます。
バナーを押すと新しい版に切り替わります。押さなければ、遊んでいる途中の盤面が
消えることはありません。アプリを完全に終了して次に起動したときは、
新しい版に切り替わった状態で開くか、再びバナーが出ます。

## 3. GitHub Pages の有効化手順

1. GitHub のリポジトリページを開く
2. 上のタブから **Settings** を開く
3. 左のメニューから **Pages** を選ぶ
4. 「Build and deployment」の **Source** を「Deploy from a branch」にする
5. **Branch** で `main` と `/ (root)` を選んで **Save**
6. 数分待つと `https://<ユーザー名>.github.io/minesweeper/` で公開されます

すべてのファイルは相対パスで書かれているので、サブディレクトリ配信でもそのまま動きます。

---

## 4. iPhone での導入手順

1. iPhone の **Safari** で公開 URL を開く（他のブラウザでは「ホーム画面に追加」ができません）
2. 画面下の **共有ボタン**（四角から矢印が出ているアイコン）を押す
3. メニューから **「ホーム画面に追加」** を選ぶ
4. 名前が「Minesweeper」になっていることを確認して **追加**
5. ホーム画面に地雷のアイコンが現れるので、そこから起動する

ホーム画面から起動すると、Safari のアドレスバーが無い全画面のアプリとして動きます。

## 5. 動作確認のチェックリスト

導入直後や更新後に、以下を確認してください。

- [ ] ホーム画面のアイコンが地雷のシルエットになっている
- [ ] ホーム画面から起動すると、アドレスバーの無い全画面で開く
- [ ] ヘッダーが Dynamic Island と重ならず、フッターがホームインジケータと重ならない
- [ ] **機内モードにしてから**ホーム画面のアイコンで起動でき、最後まで遊べる
- [ ] マスを押している間、指の下のマスが沈み込んで見える。指をずらすと沈むマスが移動する
- [ ] 盤面の外まで指を動かして離すと、何も開かない（キャンセル）
- [ ] 長押しが成立した瞬間、マスの縁が一瞬光る
- [ ] フッターのボタンで開放モード／フラグモードが切り替わり、フラグモードではフッターが赤系になる
- [ ] 数字マスをタップすると、周囲の旗が数字と一致する場合に一斉に開く（チョーディング）
- [ ] 設定（歯車）で長押し時間を変えると、試し押しのマスでその長さが体感できる
- [ ] 長押し中にテキスト選択やメニューが出ない。ダブルタップしても拡大しない
- [ ] `sw.js` のバージョンを上げて push した後、アプリを起動すると更新バナーが出る。
      押すと新しい版になり、押さなければ盤面はそのまま
